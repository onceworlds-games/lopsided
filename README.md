# Lopsided

One wobbly table for everyone. Drop stones where they score most, tip the table toward your rivals, and watch their pile slide off.

An Onceworlds game. Push drafts with the onceworlds tools (deploy_preview) and publish from https://onceworlds.com/create/lopsided.
The guide is AGENTS.md. The kit's own notes (what each file does, what to change, its tests) are in KIT.md.
